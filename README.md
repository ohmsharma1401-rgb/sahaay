# Sahay: Your Support Network

You are an expert UI/UX Designer, Product Designer and Senior Full Stack Developer.

Your task is to build a complete, modern, responsive web application named "Sahay" - an NGO Assistance Platform.

This project is a college project. The objective is to build a professional-looking, fully working prototype that demonstrates the idea clearly. Focus on a clean architecture, polished UI, and reusable components.

====================================================

PROJECT OVERVIEW

====================================================

Sahay is a platform that connects people facing family, legal and social issues with nearby verified NGOs and Lawyers.

There are four user roles:

• Citizen

• Lawyer

• NGO Owner

• Admin

Generate the complete frontend structure with Supabase authentication and role-based routing.

Do NOT implement all business logic yet.

Focus on generating an excellent UI, routing, authentication structure, layouts and reusable components.
